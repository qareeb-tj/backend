Заказ

Заказ - единица услуги, предоставляемой пользователям сервиса qareeb в виде поездки.

Модель данных

Структура заказа выглядит следующим образом

Поле Тип Описание
ID uint Уникальный идентификатор заказа в системе qareeb
ExternalID string Идентификатор заказа в системе интегратора для сверки
PickupPoint Point Координаты точки подачи машины
Status OrderStatus Текущий статус заказа
CreatedAt time.Time Время создания заказа

Статусы

Заказ может находиться в одном из следующих статусов:

Статус Описание
created Заказ создан и передан интеграторам
driver_assigned Водитель назначен и едет на точку подачи
ride_in_progress Поездка в процессе
finished Поездка успешно завершена
cancelled Заказ отменен

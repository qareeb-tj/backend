Заказ такси

Глоссарий

  • Интегратор – службы такси, с системами которых у qareeb имеется интеграция
  • Long polling - периодический опрос статуса заказа на стороне Интегратора, инциируемый нашей системой
  • Webhook - альтернатива Long polling, когда Интегратор сам оповещает нас об изменении статуса (например: машина назначена, поездка завершена)
  • Обработчик - Интегратор, который первым назначил машину

Описание

Процесс заказа такси состоит из следующих шагов:

  1. выбор пользователем точки подачи машины
  2. передача заказа в службы-интеграторы
  3. отмена заказа в службах-интеграторах, которые не успели подобрать машину первыми

Таким образом, заказ забирает себе Интегратор-Обработчик, который первым подобрал машину.

Диаграма последовательности

Компоненты

Взаимодействие с любым Интегратором может быть сведено к следующему унифицированному интерфейсу:


type TaxiServiceI interface {
    // CreateOrder creates order within the integrator system
    CreateOrder(in CreateOrderIn) (CreateOrderOut, error)

    // GetOrder gets order and it's current state
    GetOrder(orderId string) (Order, error)

    // CancelOrder cancels order if possible
    CancelOrder(orderId string) error
}

type CreateOrderIn struct {
    // Longitude and latitude of the pickup point
    PickupLat float
    PickupLong float

    // Customer's phone number for the driver to call if necessary
    CustomerPhoneNumber string
}

// Any geographical point that can be described by longitude and latitude
type Point struct {
    Long float
    Lat float
}

# Qareeb - Агрегатор Такси для Душанбе

## О проекте

Qareeb - это агрегатор такси для города Душанбе, который объединяет существующие службы такси в единую платформу. Мы помогаем пассажирам быстро найти ближайшее такси и связаться с водителем напрямую.

## Основные возможности

- 🚕 Быстрый поиск ближайших такси
- 📱 Удобное мобильное приложение
- 🗺️ Интеграция с популярными службами такси
- 💬 Поддержка на таджикском и русском языках
- ⭐️ Система рейтингов служб такси
- 📊 Статистика и отзывы

## Начало работы

### Для пассажиров

1. Скачайте приложение Qareeb из App Store или Google Play
2. Зарегистрируйтесь, указав номер телефона
3. Укажите адрес подачи и едьте!

### Для служб такси

1. Зарегистрируйте свою службу такси
2. Предоставьте необходимые документы
3. Пройдите верификацию
4. Начните получать заявки от пассажиров

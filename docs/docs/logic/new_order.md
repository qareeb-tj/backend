# Заказ такси

## Глоссарий

- `Long polling` - периодический опрос статуса заказа на стороне Интегратора, инциируемый нашей системой
- `Webhook` - альтернатива Long polling, когда Интегратор сам оповещает нас об изменении статуса (например: машина назначена, поездка завершена)
- `Обработчик` - Интегратор, который первым назначил машину

## Описание

Процесс заказа такси состоит из следующих шагов:

1. **выбор** пользователем **точки подачи** машины
2. **передача заказа** в службы-интеграторы
3. **отмена заказа** в службах-интеграторах, которые не успели подобрать машину первыми

Таким образом, заказ забирает себе Интегратор-Обработчик, который первым подобрал машину.

## Диаграма последовательности

```plantuml

title Подбор машины и передача заказа интегратору

skinparam maxMessageSize 200

actor "Пользователь" as u
participant qareeb as q
participant "Интегратор 1" as t1
participant "Интегратор 2" as t2
participant "Интегратор 3" as t3


u -> q: Указывает точку подачи и нажимает "Поехали!"
activate q
group Передача заказа и подбор машины
q -> t1: Передает заказ
q -> t2: Передает заказ
q -> t3: Передает заказ

alt Интегратор поддерживает webhook
t2 --[#green]> q: Приедет черный Volvo г/с 2255 01 TJ
else Интегратор НЕ поддерживает webhook
loop Периодический опрос статуса заказа
q -> t1: Запрашивает статус
q -> t3: Запрашивает статус
end
end

q -[#red]> t1: Отмена заказа
note top: Необходимо отменить заказ, \nчтобы таксисты не связывались с пользователем,\nкоторому уже назначена машина
q -[#red]> t3: Отмена заказа

q --[#green]> u: К вам подъедет черный Volvo г/с 2255 01 TJ
deactivate
end

```

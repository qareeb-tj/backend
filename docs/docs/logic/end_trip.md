# Завершение поездки

Поездка считается завершенной, как только qareeb получит оповещение о смене статуса со стороны интегратора (через самостоятельный периодический опрос или по webhook)

Завершение поездки включает в себя также передачу информации о сумме, расстоянии и времени поездки со стороны интегратора. Помимо отображения этой информации пользователю, онат также может представлять аналитическую ценность

## Диаграмма последовательности

```plantuml

title Завершение поездки

skinparam MaxMessageSize 200

actor "Пользователь" as u
participant qareeb as q
participant "Интегратор N" as t
actor "Водитель" as dr

dr -> t: Завершает поездку. Таксометр передает сведения о поездке своей службе

alt Интеграция по webhook
    t -[#green]> q: Поездка завершена. Передает информацию о поездке (сумма, срок, расстояние)
    q -> u: Отображает финальные сведения о поездке и предлагает оставить отзыв
    activate q
    u -> q: Оставляет отзыв
    q -> q: Регистрирует отзыв в системе
    deactivate q
else Интеграция по longpolling
    loop Периодически опрашивает интегратора
        q -> t: Запрашивает сведения и статус о поездке
    end

    ... 1 min later ...
    t --[#green]> q: Поездка завершена. Передает информацию о поездке (сумма, срок, расстояние)
end

```

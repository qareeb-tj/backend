# Интегратор

`Интегратор` - службы такси, с системами которых у `qareeb` имеется интеграция.

## Атрибуты

| Поле        | Тип       | Описание                             |
| ----------- | --------- | ------------------------------------ |
| `ID`        | uint      | Уникальный идентификатор интегратора |
| `Name`      | string    | Название службы такси                |
| `IsActive`  | bool      | Флаг активности интегратора          |
| `CreatedAt` | time.Time | Время создания записи интегратора    |
| `UpdatedAt` | time.Time | Время последнего обновления записи   |

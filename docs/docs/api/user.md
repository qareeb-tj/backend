# Пользователь

## Атрибуты

| Поле          | Тип       | Описание                                   |
| ------------- | --------- | ------------------------------------------ |
| `ID`          | uint      | Уникальный идентификатор пользователя      |
| `PhoneNumber` | string    | Номер телефона пользователя                |
| `Name`        | string    | Имя пользователя                           |
| `CreatedAt`   | time.Time | Время создания учетной записи              |
| `UpdatedAt`   | time.Time | Время последнего обновления учетной записи |
| `BirthDate`   | time.Time | Дата рождения пользователя                 |
